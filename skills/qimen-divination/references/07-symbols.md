# 转盘符号速查与条件

本页用于读盘时查基本象意。每个符号回到具体占问、宫位、时令及相邻条件；不同神名、中宫与寄宫方案先按所选盘法核实。

| 坎 1 | 北 | 水 | 蓬 / 休 |
| 坤 2 | 西南 | 土 | 芮 / 死 |

| 巽 4 | 东南 | 木 | 辅 / 杜 |

| 兑 7 | 西 | 金 | 柱 / 惊 |

表中“本位”是静态定位；某时盘的**落宫星门应以实际排盘字段为准**。中 5 的天禽与门怎样寄宫是门派争议，不把“中无门”或“寄坤二”硬充通则。

| 门（五行） | 当代事项中的入口 | 不能单独推出 |
| --- | --- | --- |
| 休（水） | 会面、关系、休整、求助 | 对方一定同意或感情结果 |
| 生（土） | 求财、生意、资源、成长 | 收益金额或中奖 |
| 伤（木） | 竞争、追索、冲突、主动推进 | 必有伤灾 |
| 杜（木） | 隐蔽、封闭、守成、研究 | 永远不成事 |
| 景（火） | 表达、文书、宣传、考试表现 | 必得名次 |
| 死（土） | 停止、结束、难推进；丧葬事另论 | 人的死亡 |
| 惊（金） | 口舌、谈判、争论、突发消息 | 必有官司 |
| 开（金） | 职务、开业、门路、公开推进 | 必录用或升迁 |

| 星（五行） | 优先辨认的象 | 适用边界 |
| --- | --- | --- |
| 蓬（水） | 冒进、涉险或扩张欲 | 报数取象法将其列为强阻力，但其他方法也按旺衰和事类变通。 |
| 芮（土） | 问题、负担、病象符号 | 不凭此诊断疾病；也须区分问事与问健康。 |
| 冲（木） | 冲劲、行动、突然启动 | 积极或急躁由门干与事项决定。 |
| 辅（木） | 辅助、教学、顾问、文教 | 帮助是否兑现要看双方宫位和现实条件。 |
| 禽（土） | 中央、统摄、寄宫争议 | 默认引擎部分已核样例存在禽芮/天芮名称差异。 |
| 心（金） | 核心、策划、思虑 | 不是“心脏有病”的诊断。 |
| 柱（金） | 言语、阻撑、碰撞 | 口才和争执都只是可选取象。 |
| 任（土） | 责任、承载、稳定 | 稳定可能是可靠，也可能是负担重。 |
| 英（火） | 可见度、形象、表达 | 桃花、宣传等须按所问选择，不一概吉。 |

## 八神与格局不单独定局

报数取象法单宫法把值符、太阴、六合、九天常作为助力，把白虎常作为阻力；螣蛇、九地、玄武等要结合事项。此评分仅在用户选择该方法的时家报数法时使用，不能因默认盘也是时家就对未报数的问题自动计分，更不能移到刻家。独立方法轮飞九宫方法对同名八神在终身盘的人格评价也并非这个现代单宫评分。若显式调用旧 `kinqimen`，其阳遁原神为“勾、雀”，而对照样例相应位置是“白虎、玄武”；时家 `atopx` 部分样例的星原值则为“禽芮”，见[排盘说明](../scripts/qimen-engine/README.md)。

乙、丙、丁为“三奇”，戊己庚辛壬癸为“六仪”；甲按六甲旬首遁藏。程序的天盘干/地盘干次序必须保留，不能把“乙+辛”和“辛+乙”交换。门星神、三奇六仪或格名可提出候选含义，但其旺衰、受迫、入墓、击刑、空亡以及主客关系会改变判断。若只有一个吉名而关键条件不明，输出“倾向待核”，不要从吉名推结果或概率。
