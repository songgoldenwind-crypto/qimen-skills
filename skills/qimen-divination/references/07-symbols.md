本页用于读盘时查基本象意。每个符号回到具体占问与默认盘实际字段。只有interpretation.allowed=true的配套盘才使用本页时间盘规则。

| 门（五行） | 当代事项中的入口 | 不能单独推出 |
| --- | --- | --- |
| 休（水） | 会面、关系、休整、求助 | 对方一定同意或感情结果 |
| 生（土） | 求财、生意、资源、成长 | 收益金额或中奖 |
| 伤（木） | 竞争、追索、冲突、主动推进 | 必有伤灾 |
| 杜（木） | 隐蔽、封闭、守成、研究 | 永远不成事 |
| 景（火） | 表达、文书、宣传、考试表现 | 必得名次 |
| 死（土） | 停止、结束、难推进；丧葬事另论 | 人的死亡 |
| 惊（金） | 口舌、谈判、争论、突发消息 | 必有官司 |
| 开（金） | 职务、开业、门路、公开推进 | 必录用或升迁 |

| 星（五行） | 优先辨认的象 | 适用边界 |
| --- | --- | --- |
| 蓬（水） | 冒进、涉险或扩张欲 | 报数取象法将其列为强阻力，但其他方法也按旺衰和事类变通。 |
| 芮（土） | 问题、负担、病象符号 | 不凭此诊断疾病；也须区分问事与问健康。 |
| 冲（木） | 冲劲、行动、突然启动 | 积极或急躁由门干与事项决定。 |
| 辅（木） | 辅助、教学、顾问、文教 | 帮助是否兑现要看双方宫位和现实条件。 |
| 禽（土） | 中央、统摄 | 默认引擎部分已核样例存在禽芮/天芮名称差异，组合原值保留。 |
| 心（金） | 核心、策划、思虑 | 不是“心脏有病”的诊断。 |
| 柱（金） | 言语、阻撑、碰撞 | 口才和争执都只是可选取象。 |
| 任（土） | 责任、承载、稳定 | 稳定可能是可靠，也可能是负担重。 |
| 英（火） | 可见度、形象、表达 | 桃花、宣传等须按所问选择，不一概吉。 |

## 八神与格局不单独定局

报数单宫法把值符、太阴、六合、九天作为主要助力，把白虎作为优先阻力；螣蛇、九地、玄武结合事项解释。只有事前报数且选择本方法时才评分。星原值为“禽芮”时记录为组合，不覆盖成“天芮”；符号无法明确对应评分时不算完整分数。

乙丙丁为三奇，戊己庚辛壬癸为六仪，甲按旬首遁藏；本版只按程序实际给出的天／地干查有序组合，不凭名称补入未定义的附格。时空读取hour_void，日空null不等于没有日空。符号含义与软件计算字段分开，不凭单一符号断事件或概率。
