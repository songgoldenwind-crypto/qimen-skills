# 专用应用：号码、出生盘、家人、住宅与择时

除独立号码映射外，以下时间盘均先检查interpretation.allowed=true，固定使用atopx时家阳盘转盘置闰和Asia/Shanghai民用时间。报数、出生、住宅和择时分别使用对应输入。

| 3 | 震3 | 太阴 | 天冲 | 伤 | 丙 |

## 出生盘与家人

取得真实出生日期、时间、出生地及时区，以出生时刻起默认配套盘。未知分钟不补，不能用当前起念盘代替。先定所问领域，再读该宫；可以只读一个领域、找机会与阻力，或逐宫读八领域。

| 宫 | 生活领域 | 家属房份 |
| --- | --- | --- |
| 坎1 | 风险、困境、健康取象 | 中男 |
| 坤2 | 家庭、婚姻、宅地 | 母亲 |
| 震3 | 工作、事业、行动 | 长男 |
| 巽4 | 学习、感情、财务线索 | 长女 |
| 乾6 | 职位、领导、资金 | 父亲 |
| 兑7 | 社交、言语、利润 | 少女 |
| 艮8 | 土地、房产、子嗣 | 少男 |
| 离9 | 形象、名声、学历 | 中女 |

长／中／少按同一性别手足排序，只有一个儿子可取长男；不按所有孩子总排行。关系不清时说明选择依据，不据宫位猜亲属真实行为、疾病或犯罪。此入口只解释固定出生领域，不提供终身流年、大运或精确事件日期算法。

## 住宅与选房

候选房比较：每房在看盘前分别报1～9，按[报数单宫](01-single-palace.md)比较。已居住宅方位：从房屋中心划八个45°扇区，记录实测朝向、平面与外部物；这两条路线分别执行。

方位分析依次：定所问人事宫；以实际神星门干作条件线索；到对应实地方位核是否有可观察的形、物、路、环境；确有不便时考虑移、遮、挡、避等现实调整。不从盘面造出建筑。视觉、安全、结构和消防以实测与专业判断为准，不声称符号已经造成疾病或破财。

## 桃花与择时择方

固定实际办事候选时刻及地点，每个候选时辰单独排同式时家盘。固定时间找合条件门宫及方向，固定方向则枚举候选时辰。会面／感情取休门，求财取生门，工作／事务取开门；时辰为两小时，中间时刻可作候选操作点，不表示10分钟换盘。

| 目标门 | 允许落宫与附加条件 |
| --- | --- |
| 休门 | 震3：天／地干均无戊；巽4：天／地干均无壬癸；兑7、乾6。桃花择时另倾向避子时。 |
| 生门 | 乾6、兑7；离9：天／地干均无辛。 |
| 开门 | 坎1、兑7；坤2：天／地干均无己；艮8：天／地干均无庚。 |

再排除目标宫的白虎、时空及五不遇时。此处定义为时干克日干且阴阳同类，时干／日干十组为 `庚/甲、辛/乙、壬/丙、癸/丁、甲/戊、乙/己、丙/庚、丁/辛、戊/壬、己/癸`。日时干只读raw.干支的日柱和时柱，不另重算四柱；时空只读hour_void。若天／地干、日时干或时空缺失，不给合格结论。兑固定为7、乾固定为6；方向用现场中心与真实坐标，不以图面上下左右代地图。

候选跨日期时分别排实际时家盘；不据单一时家盘推断全年。现场物品只作为可观察环境条件，不提供仪式性改运规则。
