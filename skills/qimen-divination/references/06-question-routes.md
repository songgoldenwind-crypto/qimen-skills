# 分类取用：一次选一路

默认基础盘为时家阳盘转盘置闰。事前报数且选择锁宫法才用单宫评分；未报数读[全盘主客](05-full-chart.md)。以下专门角色方法按题选择，输入与盘面字段齐备才启用。分类起例或寄宫未与默认盘逐项核验的方法，只作明确标注的对照；刻家不自动采用这些规则。

| 事项 | 当代入口 | 专门方法与条件 |
| --- | --- | --- |
| 求职、岗位、升迁 | 开门为职位或通道；采用日干问测人／时干事件时先声明角色。 | 任职法查开门旺衰、三奇、吉门吉格、太岁和月建来生；核心条件不全不作完整升迁格。薪酬另看生门。 |
| 考试、资格 | 文书表现可对读景门、天辅、六丁及考生宫。 | 答卷评价法取日干为考生、天辅为考官评价、六丁为文章；比较六丁旺衰、天辅与日干生克及三奇、开休生景。现代只比表现和评价关系，不换算分数或名次。 |
| 求财、生意、投资 | 生门及交易双方、资金和合同条件。 | 生门体、同宫天盘星用：分别比较用生体／体生用，再核旺衰与上下格。到账另法取时干、甲子戊及内外宫，不与体用法拼接。 |
| 婚恋、会面 | 休门为会面关系入口，按当事人分别定角色。 | 乙庚六合法取乙宫、庚宫及六合宫，比较生合刑克。替代方法以问事方作主、比较天地盘，两路择一。乙庚只作约定角色，不凭符号认定性别、婚姻身份、品行、第三者或意愿。 |
| 出行、迁移、择时择方 | 核出发地、目的地方向、候选时刻。 | 未来行动逐候选时刻排盘，按目标门、宫位及五不遇筛选；现况问事和未来选时分开，不共用当前盘代全部候选。 |
| 行人、等人 | 核年命、所往方向及是否已出发。 | 行人取年命与方位，蓬芮可作远近线索，伏吟偏不动、反吟偏动。缺年命或未核是否出发时不定归日。 |
| 远信、消息 | 核消息对象、发出方与现实进程。 | 取六丁为信，时干宫分内外；六丁受制或休囚作延迟线索。消息来与人归来分开取用。 |
| 放贷、索债 | 先定自身是出借、借款或追索方。 | 放贷取值符为财主、天乙为取财人、生门为财；索债取伤门为索债者、天乙为欠债者，再看值符与两者生克旺衰。合同及法律证据优先。 |
| 贸易、合伙 | 核交易双方、资本与利润安排。 | 贸易看生门旺衰、三奇和上下格；资本利润另法以甲子戊为资本、生门为利息。合伙另分地盘生门与天盘角色，不自动由普通求财扩展。 |
| 失物 | 核物品、最后见物位置与接触情况。 | 甲子戊为物，核宫位方向、内外、空亡及玄武与物宫关系；替代法看天地盘生合和门宫关系，两路择一。方位只作搜索提示，不认定盗窃、不指认人或停止正常查找。 |
| 健康、诉讼 | 可介绍传统取象，先回应现实可核信息。 | 不用符号诊断疾病、判生死、认罪或替代专业意见。 |

同题出现报数宫、事类宫和双方宫不同结论时，说明各方法条件与分歧，不把同盘多种解释当独立复验。传统比例用语不换算实际金额、收益率或中奖率，官职等级也不换算招聘录用或考试排名。

## 少见问题

天时、农业、年景、住宅、地理和起造先确定对象、方位与家法，再核相应取用条件；现有规则不足时说明缺口。耳鸣、雀噪、梦兆等外应必须真实发生，且有方位、时刻与对象，不从程序盘虚构外应。专用飞宫、另装卦、演数、黄黑道、符法、纳音、军阵及太乙保留独立边界，不装入普通求职、求财或婚恋盘。方法名相同或检索命中不等于所需条件已满足。
