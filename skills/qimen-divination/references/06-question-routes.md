# 具体事项：使用同一配套方法解释

以下事项只改变问题和符号在本题中的含义，不增加另一套起局、用神或应期方法。用户已选择报数锁宫时走[单宫](01-single-palace.md)；未报数走[宫位关系](05-full-chart.md)。两条方法分开，不把多个角度累计成概率。

| 事项 | 本题重点与可用入口 |
| --- | --- |
| 求职、岗位、升迁 | 固定目标职位及招聘阶段；开门可看通道与职务，实际门星神干解释助阻。薪酬资源可另看生门，不能把岗位与薪酬合为一个结论。 |
| 考试、资格、文书 | 固定考试或提交事项；景门、天辅可作表达与文教线索，回到所选宫核其他符号。不给由盘象换算的分数或名次。 |
| 求财、生意、交易 | 生门可作资源与经营入口；结合所选宫实际字段和资金、合同、进度。不给盘象推导的收益率。 |
| 婚恋、会面、沟通 | 休门可作会面入口，六合可作协作线索；双方宫位必须事前明确，不自动假定性别或第三者角色。 |
| 出行、迁移、选时 | 核实际方向和候选办事时刻；每个候选分别排默认盘，按[择时表](03-special-applications.md)筛选。 |
| 消息、等人、进展 | 固定消息对象、是否已经发出及期限；在所选宫解释推进或等待，不给未经配套计算的到达日期。 |
| 借贷、合伙、贸易 | 固定自身与另一方的真实角色、资金和合同；宫位明确才比较支持与牵制，不另装财主、债主或资本专宫。 |
| 失物、找人 | 固定对象、最后见物位置、真实方位或事前报数；本版只作所选宫的方向与情境提示，不自动指定物宫或指认他人。 |

出生领域、家属、住宅和手机号使用[特殊应用](03-special-applications.md)的独立输入。若问题所需的算法超出这些入口，说明本版不提供该方法，不临时补充其他盘法规则。
