# 盘式与时间

排盘分别核四个问题：时间单位、部件走法、起局规则、二遁方向。它们不是同一组开关；方法适用边界见[方法兼容表](04-method-compatibility.md)。

1. **时间单位：** 默认时家以时辰为基础，节气和子时边界另核；日、月、年家按各自周期。明确要求10分钟刻家时才调用对应算法，每小时分00–09、10–19等六段。保存秒数不等于每秒换盘，交节刻度也不表示固定10分钟刻家。
2. **部件走法：** 默认转盘按八宫转动，中宫通常不摆门星神；飞盘按九宫次序，中宫可参与。星仪飞布、门行宫、神轮布与季节寄中可以各有不同规定，不能只凭飞盘名称认定这些规定相同。
3. **起局规则：** 默认置闰，拆补是另一种衔接节气与三元的方法，可能得不同局数。先选方法，不按结果切换。刻家上游虽标置闰，其函数不接收置闰／拆补选项，不挪用时家校验。
4. **二遁方向：** 默认时家按用局节气，冬至一段阳遁、夏至一段阴遁。阳盘设置也可显示阴遁。刻家按时支子至巳／午至亥分阳／阴，不能称为时家精确到10分钟。

示例：2026-09-21 14:20默认时家为阴遁七局上元；显式刻家为阴遁六局下元。算法与局数不同，不拼盘；同一时辰不同事项可共时家基础盘，但各自固定人、事、用宫和期限。

```bash
python3 scripts/qimen-engine/paipan.py --datetime 2026-09-21T14:20 --timezone Asia/Shanghai
python3 scripts/qimen-engine/paipan.py --family 刻家 --datetime 2026-09-21T14:20 --timezone Asia/Shanghai
```

报数单宫在默认时家转盘上加 `--number N`；刻家不接报数。飞盘及日／月／年家须明确指定，说明它们独立的验证边界；阴盘没有经样盘核验的自动入口。完整选择见[排盘路由](09-chart-routing.md)。
