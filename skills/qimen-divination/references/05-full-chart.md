# 默认时家盘的宫位与关系

用于未报数、明确查看多个宫或比较候选事项。先确认 `interpretation.allowed=true`；使用时家阳盘转盘置闰的实际八宫字段，不沿用报数单宫评分。

## 固定选宫

先固定对象、所问事项、期限与进展。事类可从开门（职务和通道）、生门（财务和资源）、休门（会面和休整）、景门（表达和文书）进入，其他门见[符号速查](07-symbols.md)。这是本题的解释入口，不表示软件已经算出人与事的专用用神。

比较两个人、两处方向或两个方案时，先明确双方宫位如何选定；可以使用事前约定的宫、真实方位或各自预报数。没有明确选宫依据时只介绍事类相关宫的现状，不替当事人猜一个宫。

## 读取与比较

1. 保留所选宫 `sky_stem/earth_stem/door/star/spirit/hour_void` 及宫五行，天干顺序不交换。
2. 门、星、神按[符号速查](07-symbols.md)解释本题的行动、条件、助力与阻力；同宫天干仅按[干组合](02-stem-patterns.md)查表。
3. 比较已确定的宫五行、门五行与宫五行：比和作相近，某方生另一方作支持或付出，某方克另一方作牵制。写明生克方向，结合真实角色与进展，不能由生克一项定结果。
4. 时空为true时，将该宫线索写成当前兑现不足或待核；false只表示没有这一项时空，不代表全部条件成立。日空未提供，不补算。
5. 回答当前阶段、可观察的阻力与助力；候选办事时间按[择时](03-special-applications.md)分别排盘。没有本版配套的应期公式时不由宫数、格名报日期。

八宫字段解读是同一盘的多个观察角度，不是多套术数互证。星名为“禽芮”时保留组合原值；不将其他软件的天芮、寄干或神名覆盖本盘。
