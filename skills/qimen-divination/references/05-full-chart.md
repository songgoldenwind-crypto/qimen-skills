# 时家转盘的全盘主客

用于未报数、明确要求全盘，或比较人和事项的关系。默认以时家阳盘转盘置闰为底盘，使用综合关系框架；不沿用报数单宫评分。完整飞宫、季节寄中或轮飞寄门方法未由默认盘复现，当前仅使用可核的相容关系作条件化对照，详见[方法兼容表](04-method-compatibility.md)。刻家不自动迁用本页规则；特定阴盘或寄宫方法需完整原盘与同法条件。

## 固定一张盘

记录起念当地时间、时区、引擎版本、家法、盘式、起局法、局数、用局节气和旬空。已有盘保留原宫值，不按断语切换方法。中五、天禽寄宫、多干及星神名称必须保留原值；固定样例及引擎差异见[验证边界](10-validation-boundaries.md)。

## 读盘顺序

1. **定人事与主客。** 谁问、问什么、已有何进展、谁掌握结果。静态事项可先比较值符、值使、日干与时干；真实方向或动象明确时另看方位宫。日干为问测人、时干为事件是一种角色约定，须先声明适用；天地盘不永久等于某一当事人。没有预报数，不补数。
2. **选事类用宫。** 工作先看开门，财贸先看生门，感情会面先看休门。若改用乙庚婚姻、甲子戊失物等专门取用，明确具体方法并核所需角色，不叠加全部口径。工作和薪酬分别分析。
3. **比较关系。** 保留各角色宫天／地干、门、星、神、五行、位置、旬空。看人宫与事宫、天与地、门与宫生克比和，说明谁支持或牵制谁；随后核双方旺衰和实际格局。
4. **核减力与例外。** 依时令看旺相休囚，再核门迫、击刑、三奇入墓、空亡、伏吟反吟及同宫干组合。缺少字段或依赖另一盘式时标未核。同格随主客和事项变化，不因吉名忽略条件。
5. **判阶段与应期。** 先回答当前阻力、助力及可观察的转折。方法条件、原盘支干和现实期限齐备后给候选时间窗；不足时只说明快慢或待触发点。

## 条件卡

- **主客生克：** 本题若以地盘／宫为主、天盘／门为客，比和＝关系接近，门生宫＝客助主，宫生门＝主助客，门克宫＝客制主，宫克门＝主制客。关系方向与吉凶分开；旺而受克、衰而受克不可等权，衰星克旺宫也不只凭克字断败。动为客、静为主是另一种主客约定，使用前先写定。
- **冲合动静：** 未发逢冲偏启动，已发逢冲偏散；未起逢合偏停留，已起逢合偏结合。先核现实进展再选分支，星门不配合时只保留动静线索。
- **减力检查：** 五不遇时、三奇入墓、六仪击刑、门迫、空亡逐项核。吉象落空不按实吉，凶象落空不按实凶；吉星失令不必强吉，凶星失令不必强凶。
- **应期：** 先定远近与现实期限，再由冲合、空亡及支干提出候选年月日时；旬空考虑出旬。未定期限或缺支干时不机械报日期。
- **迫制定义：** 有门克宫为迫，也有宫克门称门迫的口径。写出实际门宫五行和采用定义，不能用一个迫字覆盖两种关系。五不遇时也有只取时干克日干的宽口径；本 Skill 择时限定同阴阳，按[特殊应用](03-special-applications.md)十组执行。

遇冲突先查盘式与字段，再查角色、失令、空亡、受制与事类差异；保留仍未消解的冲突。输出区分盘面原值、条件断法与当前情境推断，不把象意写成已经发生的事实。
