# 排盘路由：先选家法，再由程序定二遁

同一问题先选一条主路，不按吉凶改盘。解读前查[方法兼容表](04-method-compatibility.md)，各部件走法、中宫和起局规则须整体相容，不能只凭现代盘法标签反推算法。

| 输入或明确要求 | 入口 | 二遁与验证边界 |
| --- | --- | --- |
| 已有盘或截图 | 保留家法、盘式、起局、时间和原宫值，先核字段。 | 不另排覆盖原盘；关键参数不足时不能同盘校验。 |
| 普通起念问事、未指定家法 | `paipan.py --datetime ...`，默认时家／阳盘／转盘／置闰。 | 用局节气决定二遁。固定样例的指定字段已核，不等于全盘通验。 |
| 事前报数且选择锁宫法 | 默认时家转盘加 `--number 1..9`。 | 5转坤2，不代报、事后补数或改数；未选锁宫法不自动计分。 |
| 明确拆补 | `--family 时家 --method 拆补`。 | 独立起局规则，不挪用置闰的校验结论。 |
| 明确飞盘 | `--family 时家 --style 飞盘`。 | 可输出程序盘，但特定季节寄中、九宫寄门或飞神方案未逐项复现。 |
| 明确日／月／年家 | `--family 日家|月家|年家`。 | 日家可选置闰／拆补；当前月／年家固定阴遁且无此选择，分别标注未核部分。 |
| 明确10分钟刻家、上海时区 | `--family 刻家`，固定版本 `pan_minute(2)`。 | 按时支分二遁、时柱取三元、分柱换盘；已核多日运行与时间边界，缺少同算法专用断法。 |
| 手机号末六位造宫 | `scripts/phone_palace.py`。 | 数字映射单宫，无时间盘，不调用 `--number` 代替。 |
| 出生盘 | 真实出生时刻排默认时家盘，再按专用领域／房份法。 | 当前入口不提供八字起运或阴盘大运流年算法。 |
| 阴盘、特定寄宫或秒级换盘 | 没有对应经样盘核验的自动入口。 | 已有完整原盘可核读；不以阴遁或通用飞盘冒充阴盘，不以秒数冒充秒级盘。 |

时间与事项是不同轴。已知分钟不自动选刻家；问事按起念，择时按每个候选办事时刻，出生盘按真实出生时刻，未知分钟不造。详见[特殊应用](03-special-applications.md)。

阳盘／阴盘是盘法，二遁是布列方向。置闰与拆补可能影响用局节气，节气边界的局数和二遁需连同程序原值核对。10分钟刻家明确使用另一种时支依据，不手动改遁或借时家断法认证。

程序返回 `route.family/style/rule_requested/engine/yin_yang_dun/yin_yang_source`。引用宫位前核这些字段与原始排局、阴阳遁、节气、用局节气；缺失或矛盾时停止计算，不凭模型补盘。
