# 时家转盘的报数锁单宫

本方法先检查interpretation.allowed=true，限定atopx固定版本、Asia/Shanghai民用时间、时家阳盘转盘置闰。用户事前报出1～9，再调用默认排盘加 `--number N`；引擎及设置见[引擎说明](../scripts/qimen-engine/README.md)。

1. **固定起念与报数。** 用实际起念时间，不以未来事件发生时间代替。洛书宫位为坎1、坤2、震3、巽4、中5、乾6、兑7、艮8、离9；报5转坤2，输出同时保留原数与转宫。
2. **逐项核锁宫。** 读取八神、九星、八门、天盘干、地盘干及时空。先检查阻力，再看助力，最后解释各符号在本题中的作用。单宫是独立简化方法，不等于全盘关系法。
3. **按条件取象。** 白虎、天蓬、天芮、死门、庚和空亡作为优先核查的阻力；值符、太阴、六合、九天，天辅、天心、天任，开休生门及乙丙丁戊作为主要助力。单一符号不表示灾祸已经发生，也不保证成败。
4. **明确选用后才评分。** 吉神20、吉星20、吉门40，吉天盘干与吉地盘干各10；没有上述强阻力且总分至少60时，才达到本方法内部的“可行”线。分数不换算现实成功率，不替代实际证据。星字段为禽芮、符号对应不明或所需字段缺失时不算完整分数。
5. **保留验证范围。** 默认引擎的指定样例字段已核，但部分星字段为“禽芮”，对照为“天芮”。差异见[样盘与验证边界](10-validation-boundaries.md)，不能静默替换或扩大已核范围。

比较多个方案时，每个方案在看盘前分别固定报数。不得看结果后重报或换宫。时间不清时先补齐时间；报数事后补给或未明确选择本方法时，转读[宫位关系](05-full-chart.md)，不套单宫评分。
