# 已适配规则与所需字段

只保留当前程序盘能够配套的规则。本页列出实际可用的方法，不收录未实现方法的理论或替代断法。

## 统一排盘条件

时间盘均使用 `atopx/qimen` 固定版本、时家、阳盘、转盘、置闰和Asia/Shanghai民用时间。读取前检查 `interpretation.allowed=true`；软件能输出其他算法不表示这些规则可以迁用。样盘校验范围见[验证边界](10-validation-boundaries.md)。

| 方法 | 必要字段或输入 | 使用边界 |
| --- | --- | --- |
| 报数锁单宫 | 事前报数、`reported_number`、`locked_palace`；该宫 `sky_stem/earth_stem/door/star/spirit/hour_void`。 | 报5转坤2；原符号无法对应评分时不算完整分数。 |
| 宫位与关系 | 事类或事前选宫、宫五行；实际门星神干及时空。 | 先说明选宫依据，仅比较这些字段，不另装专用用神。 |
| 81组干组合 | 同一宫明确的 `sky_stem` 和 `earth_stem`。 | 只查有序组合与本題含义；不由名称补入其他格局。 |
| 出生领域／家属房份 | 真实出生时刻；八宫实际字段与已确认的家庭关系。 | 只读固定领域与房份，不推导大运流年或亲属真实信息。 |
| 候选住宅／实地方位 | 事前报数或明确人事宫；房屋中心、实测方向与现场情况。 | 锁宫比较和现场方位分析分别执行。 |
| 择时择方 | 每个候选时刻的同式盘；目标门宫、天／地干、白虎、时空及日时干。 | 按明确筛选表比较候选，不从当前盘外推未来全年。 |
| 手机号末六位造宫 | 六个ASCII数字与 `phone_palace.py` 输出。 | 数字独立造宫，0的处理以该映射为准；不借时间盘的旬空或寄宫规则。 |

## 缺字段时的动作

八宫的天／地干、门、星、神或 `hour_void` 不完整时，默认断盘入口停止。中5保留引擎原值，不作为第九个完整评分宫。`raw.旬空` 在默认时家来自时柱；`day_void` 与 `void_branches.day` 为 `null`，本版不使用日空规则。

时间盘与数字造宫使用各自明确的字段；一条规则有缺项时，只说明未能判断的部分，不借另一算法补齐。方法匹配和字段检查不等于现实预测准确率验证。
