# 方法兼容：按实际规则判定

先按[排盘路由](09-chart-routing.md)固定主盘。判断规则是否相容，核家法、时间单位、二遁依据、奇仪／星／门／神各自走法、中宫寄法及起局法。术语同名不等于同一算法。

## 四种使用范围

| 范围 | 可执行动作 | 边界 |
| --- | --- | --- |
| 已核盘面字段 | 同家法、同盘式、同起局法的固定样例，可对照指定字段。 | 不外推到全部日期、全宫、拆补、飞盘或刻家。 |
| 条件化取象 | 宫位原值已确定，使用与干序、门星、时令、主客及事类相符的含义。 | 象意不是第二次排盘验证，也不是无条件结果。 |
| 另法专用 | 保留该方法自身的飞转、寄宫、神名、角色和起局规则；输入及同法盘齐备后独立使用。 | 未核同法盘时仅作注明方法的对照，不添加进默认盘。 |
| 暂不支持 | 算法未落实、字段不明、条件不齐或属于其他术式。 | 说明缺口，不用另一盘、模型记忆或其他术式补齐。 |

同一方法的不同部分可处于不同范围。已核起盘字段不等于断法经现实结果验证；重复或近似规则只计同一条依据。

## 方法分流

| 具体方法 | 可用部分 | 独立条件与边界 |
| --- | --- | --- |
| 时家阳盘转盘置闰 | 默认基础盘；报数锁宫、出生领域、房份、住宅和择时各有独立步骤。 | 只核固定样例指定字段；报数评分必须事前报数，未报数用全盘关系。 |
| 同宫有序干组合 | 九个天盘干×九个地盘干；格名和条件见[81格](02-stem-patterns.md)。 | 不提供独立起局法。甲遁仪、寄宫或干序不清时停用。 |
| 飞宫与季节寄中 | 星仪按九宫飞布，门另按行宫，中五按节气寄四维；神可另按八卦轮布。 | 各部件须逐项确定。九宫飞神又是另一方案；现有通用飞盘未逐项复现这套规则。 |
| 轮飞三盘与九宫寄门 | 保留轮飞、九宫寄门、超接折补和闰法的整套约束。 | 未完成同法盘核验，不能用普通转盘或通用飞盘替代。 |
| 分类角色取用 | 考试、任职、婚姻、行人、远信、求财、借贷、贸易及失物各有取用卡。 | 独立起例、符头、寄宫未与默认盘逐项核验；在默认盘仅作方法对照。主法和替代法择一，不累计投票。 |
| 节气、八节与三元造式 | 用于分辨节气、符头、三元和部件布列。 | 不等于现代阴盘，专用造式需同法样盘。没有落实的步骤不补造。 |
| 年／月／日／时分家法 | 按各自时间单位、符头和超接规则取局。 | 当前程序能输出各家法，但时家样例不能为其他家法背书。交节刻度不是10分钟换盘。 |
| 符头、寄宫及迫制辨异 | 将不同符头、虚中合宫、寄宫、八神和迫制定义逐项比较。 | 同一术语可能有相反定义，先写实际关系，再说明所用定义。列举方案不表示同时采用。 |
| 10分钟刻家 | 显式调用固定版本 `pan_minute(2)`；按时支分二遁、时柱取三元、10分钟分柱换盘。 | 仅核运行、八宫字段和时间边界；缺少相容的专用断法，不移植时家报数、节气二遁或择时评分。 |
| 其他术式、仪式或演数 | 按独立输入与独立算法另行研究。 | 太乙、符咒、黄黑道、纳音、军阵和另装卦不进入默认问事流程。 |

## 条件卡

使用一条规则前记录：`具体方法｜家法与时限｜二遁依据｜各部件走法｜中宫寄法｜起局规则｜所需字段｜已核范围｜例外`。字段缺失写“未明”。只有可独立核实的相容条件参与主判断；完整算法不同或未核时，另列方法对照。

古式二遁方向、现代阴盘／阳盘、转盘／飞盘和置闰／拆补分属不同轴。不能因为一种方法含阴遁就判它为阴盘；也不能把不同飞布、寄宫的方案统一命名为已实现的阳盘。
