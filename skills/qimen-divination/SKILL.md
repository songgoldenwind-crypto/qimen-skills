# 奇门遁甲

先固定问题与时间，选择一种相容的盘法，再读取相应规则。只说明具体方法、触发条件和验证范围；不输出资料的书名、作者、页码、图号、编号或本地资料路径。排盘软件的版本与必要许可证独立保留。

## 固定输入与排盘

记录所问事项、对象、期限、实际进展、起念当地时间、地点及 IANA 时区。普通问事用起念时刻；出生盘用真实出生时刻；择时择方用每个候选办事时刻。只知时辰时不编造分钟。已有盘先保留原盘的方法和字段，不另排一张覆盖它。

默认调用 `scripts/qimen-engine/paipan.py`，不传 `--family`：时家、阳盘、转盘、置闰。所有脚本路径均相对本 `SKILL.md`；从其他工作目录调用时先定位 Skill 目录。首次构建及依赖见[引擎说明](scripts/qimen-engine/README.md)。

```bash
bash scripts/qimen-engine/setup-atopx.sh
python3 scripts/qimen-engine/paipan.py --datetime 2026-09-21T14:20 --timezone Asia/Shanghai
```

明确要求其他家法、飞盘或拆补时，先读[排盘路由](references/09-chart-routing.md)。不自行编写排盘公式，也不凭模型补盘。依赖失败、原盘关键字段缺失或方法矛盾时，说明缺口并停止相关计算。

阴盘／阳盘是盘法口径，阴遁／阳遁是算法决定的布列方向，转盘／飞盘是部件运行方式，置闰／拆补是起局规则。这四项分别核对。默认时家二遁由用局节气决定，不按题目或吉凶改选。10分钟刻家是另一套算法，不是时家细分；仅在明确要求且使用上海时区时启用。秒数只用于时间记录。阴盘目前没有经过样盘核验的自动起局入口；已有阴盘可按明确且相容的方法核读。

核干支、局数、用局节气、阴阳遁、天／地盘干、门、星、神、中宫及空亡，保留原值。校验范围见[样盘与验证边界](references/10-validation-boundaries.md)；通过指定样例不等于所有日期、全宫或全部家法已验证。

## 推断与输出

先回应所问，再给排盘依据与关键推断：实际时间及时区、家法、盘式、起局方法、引擎版本、二遁依据、取用角色及验证范围。每条判断保留“原盘字段 → 具体方法及条件 → 例外或减力 → 当前事项解释”。方法边界用名称说明，不用资料编号替代。

先定主客和人事宫，再比较宫与宫、天与地、门与宫；结合时令旺衰、门迫、击刑、入墓、空亡、伏吟反吟修正。条件不齐就保留待核项，不拼不同算法的字段，不按结果切换引擎。同一时辰可共基础盘，但各事项分别定人、事、用宫和期限；多次解释同盘不算独立复验。

应期先确定事件支持到哪一步，再核原盘支干、冲合、空亡及现实期限；缺少条件时只说明快慢或转折，不由一个门或数字报精确日期。单宫计分是方法内部指标，不能换算现实成功率。博彩、交易只讨论传统取象，不推导开奖号码或保证收益；盘象不用于疾病诊断、生死断言、犯罪指认或他人隐私事实。六爻六亲、梅花体用、八字大运和太乙主客算不自动混入本 Skill。
